# Million User Plan

Target: build Everything Market toward 1,000,000 South African users through search demand, seller supply, trust, partnerships and repeat usage.

## Core Strategy

Do not split the brand across multiple competing websites. Build one main destination:

- Primary brand/domain: `everythingmarket.co.za`
- Exact-match support domain: `marketplacesouthafrica.co.za`

`marketplacesouthafrica.co.za` should permanently redirect into `everythingmarket.co.za` so search authority, backlinks and brand memory consolidate into one site. The root of the secondary domain should land on `https://everythingmarket.co.za/marketplace-south-africa`, while deeper paths preserve their equivalent Everything Market URL. Use the exact-match domain in radio, flyers, posters, WhatsApp campaigns and PR because it describes the category clearly.

## Growth Loops

### Seller Sharing Loop

1. Seller posts a free ad.
2. Everything Market generates a shareable listing URL.
3. Seller shares it on WhatsApp, Facebook groups and status.
4. Buyers visit the listing.
5. Buyers discover the marketplace and post their own ads.

Build requirements:

- WhatsApp share button.
- Facebook share button.
- Copy-link button.
- Seller view count.
- Seller message count.
- “Post your own free ad” prompt on every listing.

### SEO Loop

1. Create indexable category, province and popular-search pages.
2. Get pages indexed.
3. Add fresh listings to those pages.
4. Google sends buyers.
5. Buyer activity encourages more sellers.

Build requirements:

- Category pages.
- Province pages.
- Province + category pages.
- Popular-search pages.
- Listing schema.
- Fresh sitemap.
- Google Search Console monitoring.

### Trust Loop

1. Verified sellers appear safer.
2. Buyers message verified sellers more.
3. Sellers want verification.
4. The marketplace becomes more trusted.

Build requirements:

- Verified seller landing page.
- Seller badges.
- Report listing button.
- Safety centre.
- Review/rating system.

## Domain Strategy

Use `marketplacesouthafrica.co.za` as:

- A memorable campaign domain.
- A redirect that strengthens `everythingmarket.co.za`.
- A phrase to include in PR, social bios and backlinks.
- A QR code landing URL for print/offline campaigns.

Avoid:

- Duplicating the same site on both domains.
- Publishing the same pages on both domains.
- Splitting backlinks between domains.

Best setup:

- 301 redirect `marketplacesouthafrica.co.za/` to `https://everythingmarket.co.za/marketplace-south-africa`.
- 301 redirect all other `marketplacesouthafrica.co.za/*` traffic to `https://everythingmarket.co.za/*`.
- Add both domains to Google Search Console.
- Submit the canonical sitemap for `everythingmarket.co.za`.
- Use `marketplacesouthafrica.co.za` in offline/social campaigns where clarity matters.
